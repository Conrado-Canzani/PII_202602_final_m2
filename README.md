# Final Programación II: código de la Parte I

Este repositorio contiene el código del ejercicio de análisis de la Parte I (sección B) del final.

## Ejecutar

```bash
dotnet run --project src/Aves
```

## Consigna (Parte II, sección C)

1. Clone este repositorio y cree una branch llamada `final/Apellido_Nombre` (sin tildes ni espacios; por ejemplo, `final/Perez_Juan`):

   ```bash
   git checkout -b final/Perez_Juan
   ```

2. En esa branch, corrija el diseño para que respete el principio que identificó en la Parte I. El programa debe ejecutarse sin lanzar excepciones y cada ave debe conservar únicamente los comportamientos que realmente tiene: el canario come, vuela y canta; el pingüino come.

3. Al terminar, suba la branch al repositorio:

   ```bash
   git push -u origin final/Perez_Juan
   ```
